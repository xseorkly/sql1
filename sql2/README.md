# SQL2 — Licence 1 CPES scientifique

Suite de [SQL1](https://xseorkly.github.io/sql1/) dans le même dépôt, sans changement du contenu SQL1.

## Programme de 14 heures (7 séances)
1. Tables, relations, clés primaires / étrangères.
2. INNER JOIN entre deux tables.
3. Jointures sur trois tables, filtres et alias.
4. LEFT JOIN, valeurs manquantes, absence de correspondance.
5. Jointures + GROUP BY/HAVING, statistiques, doublons.
6. CREATE TABLE, INSERT, UPDATE, DELETE, contraintes.
7. Entraînement type examen / TP de synthèse.

## Fonctionnement
- Ouvrir https://xseorkly.github.io/sql1/sql2/
- Cours détaillés, exemples sur base scientifique locale, exercices variés, quiz, examen et bac à sable.
- Moteur sql.js réutilisé depuis ../assets/vendor ; les bases sont créées **en mémoire** dans le navigateur.
- Chaque tentative est isolée : même les commandes UPDATE, DELETE et DROP ne modifient aucun fichier.
- Résultats et progression stockés localement dans le navigateur (localStorage SQL2.v1).
- Quelques questions de réflexion nécessitent une autoévaluation, signalée explicitement.
- Toutes les valeurs et identités étudiantes sont fictives.

## Contenus
Les exemples sont rédigés spécialement pour ce cours et s'inspirent des types de problèmes présents dans les enseignements universitaires de bases de données (Université Lyon 2, Université de Toulon, Microsoft Learn).
